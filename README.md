# 大数据二班的课表

一个面向大学生的静态课程表 Web 应用，整合周课表、今日安排、空闲时间、请假记录、便签墙、课程详情、校园地图、冲突检测和上课提醒。

- 无需后端和账号体系
- 数据默认保存在浏览器本地
- 支持 JSON 导入/导出、ICS 日历导出和桌面通知
- 支持 PWA 离线缓存和“添加到主屏幕”
- 支持桌面端与移动端
- 公开版本已移除真实姓名、完整学号和原始课表文件信息

## 功能

- 周课表：按周查看课程、节假日、调休和当前时间线
- 今日：展示当天课程、下一节课倒计时和即将到来的假期
- 空闲：按周查看无课时间
- 请假：通过表单记录请假类型、原因和时段，并查看请假流程指引
- 便签墙：可拖动便签，支持课程关联便签
- 课程：查看课程信息、学分、教师、考核方式和成绩构成
- 冲突检测：自动检测同一天、同一节次且至少有一周重叠的课程
- 校园：查看校园地点、宿舍到教学楼的路线和步行估算
- 设置：学期开始日期、总周数、法定节假日、调休、作息时间、数据导入导出
- 提醒：桌面通知、页面提醒条和 ICS 导出
- PWA：首次加载后可离线打开，断网时显示离线提示
- 管理员：初始账号 `admin`，初始密码 `123456`，可查看个人信息并集中管理便签
- 分享：动态生成二维码、复制链接和系统分享
- 可访问性：语义化导航、标签页键盘操作、ARIA 状态和焦点管理

## 本地运行

推荐使用本地静态服务器，而不是直接双击打开：

```bash
npx serve .
```

也可以用任意静态服务器，例如 Python：

```bash
python -m http.server 8000
```

访问：

```text
http://localhost:8000/
```

PWA 的 Service Worker 需要 `http://localhost` 或 HTTPS 环境才能注册。直接双击 `file://` 打开时，课表功能仍可使用，但离线缓存不会启用。

## 数据与隐私

公开版本包含示例数据，不包含真实个人信息。

- `schedule.js` 保存默认示例课表。
- 用户新增的课程、便签、请假记录、考核修改和设置保存在浏览器 `localStorage`。
- 可通过“设置 → 导出数据”备份为 JSON。
- 可通过“设置 → 导入数据”恢复。
- “清除本地数据”只清除当前浏览器中的用户数据，不会影响服务器上的默认数据。
- 所有用户数据都留在当前浏览器，不会上传到服务器。

> 如果要部署自己的真实课表，请在导入前确认目标设备可信，并在公开前删除姓名、学号、联系方式等个人信息。

## 本次优化内容

### 隐私脱敏

- 移除真实姓名。
- 将完整学号替换为脱敏示例值。
- 移除原始 PDF 文件信息。
- 默认数据改为可公开的示例数据。

### 持久化修复

- 新增本地存储版本：`wb-schedule-v2`。
- 保存时同时持久化基础课表、用户课程、便签、请假和设置。
- 启动时优先恢复用户数据，避免刷新后新增课程丢失。
- 兼容旧的 `wb-schedule-v1` 存储。
- 自动保存数据版本和当前周次。

### 单文件拆分

- 页面结构移至 `index.html`。
- 样式移至 `styles.css`。
- 领域逻辑移至 `schedule-core.js`。
- 默认数据移至 `schedule.js` 和 `schedule.json`。
- 业务逻辑移至 `app.js`。
- 保留纯静态部署方式，不要求构建工具。

### 表单替代 prompt

- 新增课程、编辑考核方式和标记请假均改为页面内表单弹窗。
- 表单包含字段校验、错误提示、键盘 Escape 关闭和移动端单列布局。
- 页面不再依赖浏览器原生 `prompt()`。

### 课程冲突检测

- 自动检测同一天、节次重叠且至少有一周同时有课的课程。
- 支持每周、单周、双周判断。
- 周次不重叠或单双周错开的课程不会误报。
- 添加课程后自动重新检测，并在课程页面显示结果。

### PWA 离线缓存

- 新增 Web App Manifest。
- 新增 Service Worker App Shell 缓存。
- 导航请求优先网络，离线时回退到缓存页面。
- 静态资源采用缓存优先并后台更新。
- 断网时显示离线状态条。

### 管理员模式

- 初始账号：`admin`
- 初始密码：`123456`
- 可查看姓名、学号、学期、校区、便签数量、请假记录和本地数据量。
- 可集中查看、修改、保存和删除全部便签。
- 清空全部便签需要管理员登录。
- 登录状态保存在 `sessionStorage`，关闭标签页后自动失效。
- 首次登录时会在本地生成加盐哈希，不直接保存明文密码。
- 这是课程项目演示权限，不是服务器级安全认证；公开部署时请不要存放真实敏感信息。
- 登录后可以在管理员面板中修改密码。

### 分享卡片与二维码

- 增加 Open Graph 和 Twitter Card 元数据。
- 增加 1200x630 分享封面。
- 增加顶部分享按钮。

- 支持复制链接和系统原生分享。

## 已知限制

- 课表数据目前通过静态文件维护，暂未接入真实教务系统。
- 桌面通知依赖浏览器授权，移动端浏览器支持情况可能不同。
- LocalStorage 只对当前浏览器和当前域名有效，不会自动跨设备同步。
- 节假日和调休数据需要手动更新。
- 课程卡片数量较多时，移动端仍需要横向滚动查看一周全部课程。
- PWA 安装能力取决于浏览器和部署环境，必须使用 HTTPS 或 localhost。
- 管理员模式是纯前端演示权限，任何能看到源码的人都可以分析登录逻辑，不能用于真实权限控制。
